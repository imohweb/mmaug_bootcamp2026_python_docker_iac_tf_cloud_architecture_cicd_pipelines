# Agent runbook entry point

The standardized instructions for agents **and workshop participants** now live
in [skills.md](skills.md). Read that file before running the app, changing
infrastructure or invoking CI/CD.

It covers local startup, the two-web-app cloud architecture, OIDC environment
`dev`, storage bootstrap, Terraform plan/apply ownership, indexed knowledge,
application releases, verification and permission boundaries.

This file keeps the requested `AGENT.md` entry point without duplicating a
second set of commands. Neither `AGENT.md` nor `skills.md` should be assumed to
load automatically as `AGENTS.md` or an installed `SKILL.md`.
