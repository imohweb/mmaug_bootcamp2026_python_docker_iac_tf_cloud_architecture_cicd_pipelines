# Technical troubleshooting

## Application is slow or not loading
Ask the customer to check the public status page first. Then clear the browser
cache, try a private window and a different network. Collect the time of the
problem, the browser and version, and a screenshot of any error message.

## Error messages and error codes
Error codes beginning with **E4** are input or permission problems the customer
can usually fix. Codes beginning with **E5** are service-side errors; apologise,
record the code and timestamp, and escalate to a technical specialist.

## Mobile app crashes
Ask the customer to update to the latest version from the app store, restart the
device and reinstall the app if the crash continues. Collect the device model and
operating-system version.

## Integrations and API
API keys are created under **Settings > Developer**. Requests are limited to
100 per minute per key; HTTP 429 means the limit was exceeded. Never ask the
customer to paste an API key into a support request.
